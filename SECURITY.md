# Security Policy

Report vulnerabilities through GitHub private vulnerability reporting rather
than a public issue. Include the version, impact, and a minimal reproduction.

Feeds are untrusted data. The collector strips markup and controls, caps excerpts,
flags instruction-like text, validates schemes and hosts, and never executes or
browses links found inside summaries. Consumers must escape output and must not
treat normalized text as assistant instructions.

No credentials are required. Never add cookies, tokens, private feed URLs, or
personal data to configuration, fixtures, logs, exports, or issues. Do not use
this collector to bypass authentication, CAPTCHA, paywalls, robots controls, or
provider redistribution restrictions.
